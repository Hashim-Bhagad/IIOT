Traps to leave out

  • Hide mastered topics: a lucky answer is weak evidence of recall.
  • Skip after two correct answers: guessing can create false confidence.
  • Gate explanations behind mistakes: a beginner needs help on demand.
  • Unlock a picture trail: extra progression mechanics cost revision time.

How the three ideas work

01 · An answer slip you can read at a glance

After checking an answer, show three short rows: clue, rule, and choice. The clue points to the phrase that matters in this question. The rule preserves the condition that makes the answer true. Keep the original explanation expandable and keep the source key and any ambiguity notice visible or directly accessible.

Clue
“Measures temperature”
Rule
A sensor turns a physical measurement into a signal.
Choice
Choose sensor; an actuator performs an action.

Load-bearing risk: shortening a rule can erase its conditions.

First step: define a typed brief and write five examples against their original explanations.

Child ideas: folded answer label · “only when” qualifier · retry deck · tiny rule picture · hidden-answer recall.

02 · A bounded first pass through a week

Start each week with five testable points and a single figure. Use a flowchart for a sequence and a comparison picture for a distinction. A practice button gives the overview an immediate purpose. Link wrong answers back to the relevant lesson so the student can expand only the detail they need.

Load-bearing risk: a quick overview can imply complete exam coverage.

First step: create a typed week snapshot and map each point to existing assignment questions.

Child ideas: trap strip · diagram replay · missed/untouched topic route · concept comparisons.

03 · Pictures that settle a confusing pair

Place two simple pictures side by side with one job under each. Add a decisive clue that explains which concept the question describes. Reuse the same visual in the lesson and relevant answer feedback. Keep conditional distinctions in the caption so the picture does not overstate a rule.

Load-bearing risk: a memorable contrast can become a misleading absolute.

First step: make three contrast cards and map them to existing quiz questions.

Child ideas: three-way edge/fog/cloud · decisive-word highlights · picture-only recall · missed-contrast deck.
